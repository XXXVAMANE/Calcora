# Скачать готовый сайт

Эта ветка содержит готовую статическую сборку в папке `ready-site`.

1. На GitHub откройте ветку `codex/calcora-download`.
2. Нажмите зелёную кнопку **Code**, затем **Download ZIP**.
3. Распакуйте скачанный архив.
4. Найдите папку **ready-site**: внутри должны быть `index.html`, `_astro`, `ru` и `calculators`.
5. Для публикации перетащите всю папку **ready-site** в Netlify Drop: https://app.netlify.com/drop . GitHub подключать к Netlify не нужно. Если вход через GitHub не работает, используйте электронную почту.

Эта сборка уже готова: Node.js и команды установки для загрузки на статический хостинг не нужны. Чтобы открыть её локально, нужен веб-сервер, обслуживающий папку `ready-site` как корень сайта; простое открытие `index.html` не обеспечивает загрузку всех ресурсов и переходы между страницами.

Работают английская и русская версии и четыре локальных калькулятора. ИИ-объяснения требуют отдельного сервера с ключом API. До настройки настоящего адреса сайт закрыт от индексации. После получения адреса нужно пересобрать проект с `PUBLIC_SITE_URL`, чтобы включить корректное SEO.

Сборка здесь — снимок текущей версии. Для дальнейших изменений используйте исходники из `main`, выполните `npm ci`, затем `npm run build`; новые готовые файлы появятся в `dist`.
